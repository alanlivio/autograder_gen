YAML Configuration Example

A sample high-level autograder_gen.yaml configuration file containing metadata and custom grading test suites:

version: "0.1"
language: "python"
global_time_limit: 5000
setup_commands:
  - pip install numpy
files_necessary:
  - math_utils.py
questions:
  - name: "Question 1: Fibonacci Sequence"
    marking_items:
      - name: "Fibonacci function exists"
        total_mark: 2.0
        check_type: "file_exists"
      - name: "Fibonacci standard cases"
        total_mark: 5.0
        check_type: "output_comparison"
        test_cases:
          - input: "5"
            output: "5"
          - input: "10"
            output: "55"
